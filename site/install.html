安装步骤

四步，装进抖音网页。

01

下载并解压扩展

拿到扩展 zip 后解压到一个固定目录。不要放在下载临时目录里，Chrome 会在下次启动时找不到它。

02

加载已解压的扩展

地址栏输入 chrome://extensions（Edge 是 edge://extensions），开启「开发者模式」，点「加载已解压的扩展程序」，选择解压后的文件夹。

03

开通 DeepSeek API，创建 Key

打开 DeepSeek 开放平台，按平台要求注册、充值，在「API Keys」里创建一个 Key。Key 通常只完整显示一次，复制后自己保存。

04

在扩展里选「直接用 API Key」并测试

点浏览器工具栏的猫娘图标，在「方式」里选「直接用 API Key」，粘贴 Key，确认「API 地址」是 https://api.deepseek.com，点「测试连接」——它会拿你的 Key 向这个地址要一次模型列表，Key 不对会当场报错，不会花额度。通过后保存。首次测试时浏览器会向该地址申请访问权限；允许后刷新抖音页面。

为什么是 BYOK？

你的 Key，你的额度，你的请求。

公开版不提供共享 Key，也不代收 API 费用。每个人的请求直接发往自己配置的模型服务，插件没有能力读取你的账单，也没有我们的后端中转。

安全边界 Key 存在扩展的 chrome.storage.local，抖音页面脚本读不到，也不上传给我们。但它不是加密保险箱：能读你浏览器配置文件的人仍可能拿到，泄露后请立刻去平台吊销。

安装问题

常见卡点。

一定要自己开通 API 吗？
是。公开版走 BYOK（Bring Your Own Key）：你在 DeepSeek 开放平台注册、充值、创建 Key，再填进扩展。插件不卖 Key、不代收、不共享额度；具体价格、可用地区和实名要求以平台为准。
API Key 安全吗？
Key 存在扩展的 chrome.storage.local，不写进抖音网页，也不上传给我们；请求只发往你配置的 「API 地址」，默认是 DeepSeek 官方地址。它不是加密保险箱，能读你浏览器配置文件的人或高权限软件仍可能拿到；不要共用设备，不要把 Key 发到群里或陌生网页，泄露后立刻去平台吊销。
为什么 Chrome 提示“无法加载扩展”？
通常是没有选择解压后的文件夹，或者文件夹里缺少 manifest.json。重新解压，确认选择的目录里能直接看到 manifest.json，再加载一次。
支持 Firefox / Safari 吗？
不支持。插件依赖 Manifest V3 的后台 service worker，而 Firefox 目前还没有实现它；Safari 需要另行封装，暂时没有计划。在 Firefox 或 Safari 里装不上，也没有替代的安装方式。请用 Chromium 内核的桌面浏览器：Chrome 116+、Edge 116+，或 Brave、Opera、Vivaldi 等。
每次启动 Chrome 都提示“请停用开发者模式扩展程序”？
这是用开发者模式加载未上架扩展的正常提示，不是你装错了。点掉提示即可，扩展会继续工作。想彻底消掉它只能等扩展上架浏览器商店；目前暂时没有上架计划。另外这种安装方式不会自动更新，换版本需要重新下载 zip 并替换目录。
装完后抖音页面没有悬浮球？
先在扩展管理页确认「上头了喵喵」是开启状态，刷新抖音页面。再打开扩展设置，确认「方式」选的是「直接用 API Key」、Key 已填写、测试连接通过；没有 Key 时插件不会主动请求模型。
测试连接一直失败？
「测试连接」会用你的 Key 请求该地址的模型列表，所以失败信息能直接对上是哪一类：提示 Key 无效，多半是复制不全或已被吊销；提示额度或限流，是平台账户的问题；提示连不上，先看「API 地址」是否是 https://api.deepseek.com，以及首次测试时浏览器弹出的访问权限有没有允许。如果用的是兼容网关，确认地址支持 OpenAI 风格接口；不要填来路不明的中转地址，那等于把 Key 交给对方。平台故障也会表现为连接失败。
还能用本地 Fastify 模式吗？
可以，原来的 serverUrl + APP_TOKEN 模式仍然保留，适合本地调试、离线 Mock 或不想把 Key 存在浏览器里的场景。公开用户不需要它；在扩展设置的「方式」里切回「连自己的服务（需先启动）」，再填服务地址和访问令牌即可。
会不会影响抖音账号？
插件只读当前视频的公开信息和页面文案，不点赞、不评论、不关注、不刷数据。它不绕过登录、不自动操作账号。仍建议遵守抖音的用户协议。
