先启动本地服务

扩展的聊天、分析和情绪提示都走这个 Fastify 服务。模型 Key 只在服务端读取，浏览器只拿到一个访问令牌。

server · 启动命令 
# 在项目根目录执行（Windows PowerShell / cmd）
cd server
npm.cmd install
copy .env.local.example .env.local
npm.cmd run dev

# .env.local 里至少要有：
MODEL_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的模型 Key
APP_TOKEN=你自己的长随机串
1Node.js 22+，在 server/ 安装依赖。
2把 .env.local.example 复制成 .env.local，填模型 Key 和 APP_TOKEN。
3运行 npm.cmd run dev，看到 127.0.0.1:8787 就说明服务起来了。
默认本机地址；如果服务换了端口，这里一起改。
演示页不会发送令牌；正式扩展把它存在 chrome.storage.local，用来请求本机服务。
设备 ID（可选） 用于区分不同浏览器的限时额度，通常不用手动填。
为什么是本地服务 模型 Key、prompt、语音过滤和 SSE 都在 Fastify 里；扩展只负责页面和交互。这样浏览器里没有模型 Key，也不会把 Key 暴露给网页。

装到浏览器里

当前公开版是“扩展 + 本地 Fastify 服务”。扩展包可以单独分发，服务端按上面的步骤启动。

01下载扩展 zip，解压到一个固定目录。
02打开 chrome://extensions，开启「开发者模式」。
03点「加载已解压的扩展程序」，选择解压后的文件夹。
04打开抖音网页，在设置里填刚才的服务地址和 APP_TOKEN。
现在就能做 先保存服务配置和回复偏好，或者去 Demo 里试玩。正式安装包发布后，这份配置不需要重填。
