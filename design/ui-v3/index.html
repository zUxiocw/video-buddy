FAQ

你可能想问。

它和 BibiGPT、视频总结插件有什么区别？
总结工具回答“这视频讲了什么”；喵喵陪你刷回答“你现在是什么感觉”。它不替你省时间，也不生成学习笔记，重点是在你刷视频的当下，主动接一句话、陪你聊两句。
一定要自己开通 API 吗？
是。公开版走 BYOK（Bring Your Own Key）：你在 DeepSeek 开放平台注册、充值、创建 Key，再填进扩展。插件不卖 Key、不代收、不共享额度；具体价格、可用地区和实名要求以平台为准。
API Key 存在哪里？安全吗？
存在扩展的 chrome.storage.local，不写进抖音网页，也不上传给我们；请求只发往你配置的 「API 地址」，默认是 DeepSeek 官方地址。它不是加密保险箱：能读你浏览器配置文件的人或高权限软件仍可能拿到。不要共用设备，不要把 Key 发到群里或陌生网页，泄露后立刻去平台吊销。
还要启动本地 Fastify 服务吗？
不需要。BYOK 模式只装扩展；原来的 serverUrl + APP_TOKEN 模式仍然保留给本地调试、离线 Mock，或不想把 Key 存在浏览器里的开发者。
截图会不会上传到你们服务器？
不会经过我们的服务器。截图会随请求发给你配置的模型服务（默认 DeepSeek），用于理解画面；你也可以在设置里关闭截图，只让它根据文案和标签接话。
会不会自动点赞、评论，导致账号风险？
不会。这个插件坚持只读：不点赞、不评论、不关注、不刷数据。它只读取当前视频的公开信息和页面文案。
它会怎么管我刷多久？
在扩展设置里打开“刷视频限时”，设每日额度和关页前的停留秒数。只统计视频正在播放、且页面在前台的时间；到点它先说一句，再把标签页关掉。默认是关闭的，不会装完就替你关页。
关掉的页面还能马上打开吗？
可以，但会进入冷却（默认 10 分钟）。冷却期内再打开，它会说一句再关一次，不会重新给你一整份额度。冷却结束后重新计时。
手机能用吗？
目前只做桌面浏览器的抖音网页版（Chrome / Edge 116+）。手机 App 不在范围内。
