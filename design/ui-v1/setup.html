装到浏览器里

公开版会以 Chrome / Edge 扩展的形式发布。当前是 UI 预览，安装包在“自带 API Key”接入完成后开放。

01下载扩展 zip，解压到一个固定目录。
02打开 chrome://extensions，开启「开发者模式」。
03点「加载已解压的扩展程序」，选择解压后的文件夹。
04打开抖音网页，在设置里填刚才的 API 配置。
现在就能做 先保存配置，或者去 Demo 里试玩。正式安装包发布后，这份配置不需要重填。
