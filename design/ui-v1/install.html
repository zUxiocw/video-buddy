安装步骤

四步，装进抖音网页。

01

下载并解压

拿到 shangtou-meowmeow.zip 后解压到一个固定目录。不要放在下载临时目录里，Chrome 会在下次启动时找不到它。

02

打开扩展管理页

地址栏输入 chrome://extensions（Edge 是 edge://extensions），打开右上角「开发者模式」。

03

加载已解压的扩展

点「加载已解压的扩展程序」，选择解压后的文件夹。看到「喵喵陪你刷」出现就成功了。

04

填自己的 API

打开抖音网页，点悬浮球右上角的设置，填 Base URL、API Key、模型名。先点「测试连接」，再开始刷。

安装问题

常见卡点。

为什么 Chrome 提示“无法加载扩展”？
通常是没有选择解压后的文件夹，或者文件夹里缺少 manifest.json。重新解压，确认选择的目录里能直接看到 manifest.json，再加载一次。
装完后抖音页面没有悬浮球？
先在扩展管理页确认「喵喵陪你刷」是开启状态，然后刷新抖音页面。悬浮球默认在右下角，可能被页面其他按钮挡住，拖动一下就能看到。
API 测试一直失败？
先检查 Base URL 是否以 http:// 或 https:// 开头，模型名是否和服务商一致。DeepSeek 默认是 https://api.deepseek.com + deepseek-chat。本地 Ollama 则填 http://127.0.0.1:11434/v1。
会不会影响抖音账号？
插件只读当前视频的公开信息和页面文案，不点赞、不评论、不关注、不刷数据。它不绕过登录、不自动操作账号。仍建议遵守抖音的用户协议。
