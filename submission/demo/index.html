FAQ

你可能想问。

它和 BibiGPT、视频总结插件有什么区别？
总结工具回答“这视频讲了什么”；喵喵陪你刷回答“你现在是什么感觉”。它不替你省时间，也不生成学习笔记，重点是在你刷视频的当下，主动接一句话、陪你聊两句。
一定要自己开通 API 吗？
是。公开版走 BYOK（Bring Your Own Key）：你在 DeepSeek 开放平台注册、充值、创建 Key，再填进扩展。插件不卖 Key、不代收、不共享额度；具体价格、可用地区和实名要求以平台为准。
API Key 存在哪里？安全吗？
存在扩展的 chrome.storage.local，不写进抖音网页，也不上传给我们；请求只发往你配置的 「API 地址」，默认是 DeepSeek 官方地址。它不是加密保险箱：能读你浏览器配置文件的人或高权限软件仍可能拿到。不要共用设备，不要把 Key 发到群里或陌生网页，泄露后立刻去平台吊销。
还要启动本地 Fastify 服务吗？
不需要。BYOK 模式只装扩展；原来的 serverUrl + APP_TOKEN 模式仍然保留给本地调试、离线 Mock，或不想把 Key 存在浏览器里的开发者。
截图会不会上传到你们服务器？
不会经过我们的服务器。截图会随请求发给你配置的模型服务（默认 DeepSeek），用于理解画面；你也可以在设置里关掉「把画面截图一起发给模型」，只让它根据文案和标签接话。
会不会自动点赞、评论，导致账号风险？
不会。这个插件坚持只读：不点赞、不评论、不关注、不刷数据。它只读取当前视频的公开信息和页面文案。
它会怎么管我刷多久？
「到点关视频」始终开启，不能关闭。第一次对话，或停留 10 秒后的第一句，会先报一次当次设的额度；之后只统计视频正在播放、且页面在前台的时间。到点它先说一句，5 秒后关掉标签页。每日时长和冷静期仍可在扩展设置里调。
为什么它会一直催我？
默认沉默 5 分钟后开始，可以在设置里调 1–10 分钟。开始后每 5 秒催一次，直到你回它；催的时候，视频停留计时暂停，你主动回一句就恢复并清零计数。5 秒间隔固定。
催满次数会怎样？能改吗？
从这次沉默开始，AI 每催一句算一次；默认催满 10 次就关页，并进入冷静期，规定时间内再打开会被再关一次。次数可以在扩展设置里调，范围 3–60，默认 10；正常聊天和视频反应不计入这个次数。到点关视频始终开启，不存在关闭后不关页的情况。
关掉的页面还能马上打开吗？
不能立刻打开。到点关页或催满关页都会进入冷静期（默认 10 分钟，可在设置里调）；冷却期内再打开，它会说一句再关一次，不会重新给你一整份额度。冷却结束后重新计时。
支持哪些浏览器？
只支持 Chromium 内核的桌面浏览器：Chrome 116+、Edge 116+，以及 Brave、Opera、Vivaldi 等同样基于 Chromium 的浏览器。

Firefox 和 Safari 目前不支持。Firefox 的 Manifest V3 还没有后台 service worker，这个插件依赖它；Safari 需要另行封装，暂时没有计划。用这两者打开抖音网页，不会出现悬浮球。

浏览器版本可以在地址栏输入 chrome://version（Edge 是 edge://version）查看。
手机能用吗？
不能。扩展只装在桌面浏览器的抖音网页版，手机 App 和移动浏览器都不在范围内。
