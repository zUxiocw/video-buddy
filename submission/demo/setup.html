不需要我们的账号 · 本页不收 Key

先开通 DeepSeek API

API 按量计费，需要你自己的账号和余额。插件不卖 Key、不代充、不共享额度；用多少由你和 DeepSeek 结算。

打开 DeepSeek 开放平台 看 API 文档
1注册 / 登录 DeepSeek 开放平台，按平台要求完成认证和充值。
2确认账户余额和计费方式。API 按调用量扣费，是否有赠送额度以平台为准。
3在「API Keys」里创建一个 Key，复制保存；它通常只完整显示一次。
先别急着粘贴 API Key 等同于账户余额。不要发到群里、截图里或任何网页；本页不会要求你填写 Key。

把扩展装进浏览器

BYOK 模式只需要扩展，不需要 Node.js，也不需要本地 Fastify 服务。只支持 Chromium 内核的桌面浏览器（Chrome 116+ / Edge 116+ 等），Firefox 和 Safari 不支持。

01下载扩展 zip，解压到一个固定目录。
02打开 chrome://extensions（Edge 是 edge://extensions），开启「开发者模式」。
03点「加载已解压的扩展程序」，选择解压后的文件夹。
安装包在哪 点首页或安装页的下载按钮拿 zip；如果那里提示还没放包，可以先试玩，或照完整的安装说明手动加载 extension/ 目录。
完整安装说明

在扩展里填 Key

网站不接收 Key。点浏览器工具栏的猫娘图标，在「方式」里选「直接用 API Key」，粘贴 Key，点「测试连接」——它会拿这个 Key 向「API 地址」要一次模型列表，Key 不对会当场报错，也不花额度。通过后保存。

开发者：还想用本地 Fastify 模式？

原有的 serverUrl + APP_TOKEN 模式仍然保留，适合本地调试、离线 Mock，或不想把 Key 存在浏览器里的场景。公开用户不需要它。

server · 开发者模式 
# 在项目根目录执行（Windows PowerShell / cmd）
cd server
npm.cmd install
copy .env.local.example .env.local
npm.cmd run dev

# .env.local 里至少要有：
MODEL_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的模型 Key
APP_TOKEN=你自己的长随机串
